# BTP Mid-Term Report: Multi-Robot Task Orchestration for Construction Assembly

## 1. Project Overview
- **Final Goal:** To develop a highly robust and scalable system where multiple heterogeneous robots (e.g., Franka Panda arm, shuttle, mortar dispenser) work collaboratively, orchestrated by an LLM (Large Language Model) brain, to construct a complex brick wall. Key objectives include achieving precise millimeter-level placement, developing a scalable task orchestration framework, and ensuring seamless and collision-free multi-robot coordination in a dynamic environment. This multi-agent system aims to bridge the gap between high-level cognitive planning and low-level control, providing a foundation for fully automated masonry and construction tasks in unstructured environments.

## 2. Progress Till Now
Based on the current codebase, significant milestones have been achieved in establishing the core infrastructure for the project:
- **Simulation Environment:** A fully functional and physically accurate PyBullet simulation environment has been established (`wall_sim/scene.py`). This environment comes complete with realistic brick models, organized pallet stacks for material supply, and a dedicated pedestal for the construction area. The simulation serves as a robust testing ground for all robotic operations and coordination algorithms, providing a safe, repeatable, and highly visual platform for rapid prototyping and experimentation.
- **Robot Control & Kinematics:** 
  - **Panda Arm (`panda_arm.py`):** The control scheme for the 7-DOF Franka Panda arm has been successfully implemented for complex brick picking and placing operations. This includes sophisticated grasp-error compensation mechanisms to ensure a strict 1-2mm placement precision, which is critical for structural stability and alignment in masonry.
  - **Shuttle & Mortar Bot:** We have developed kinematic transport and dispensing robots equipped with collision-safe routing algorithms. These ancillary robots are capable of navigating the workspace efficiently, ensuring the timely delivery of materials (bricks and simulated mortar) to the primary manipulator while continuously avoiding dynamic obstacles.
  - **Generator-based Actions:** The core robot behaviors are uniquely implemented as Python generators. This specific architectural decision allows for concurrent, step-by-step execution of complex state machines without the significant overhead, race conditions, and synchronization issues that are typically associated with complex multithreading in Python robotics environments.
- **Task Orchestration (DAG):** Task orchestration is not started yet. We plan to build a robust dependency graph and scheduler to sequence operations in the future.
- **Vision Integration (`run_demo3_multi_robot.py`):** We have successfully integrated a 3D Computer Vision pipeline utilizing OpenCV RGB-D data and Point Cloud Principal Component Analysis (PCA) for our simulated overhead camera detection system. This sophisticated perception module allows the system to accurately detect the orientation of objects, successfully grasp tilted or misplaced bricks, and perform real-time kinematic reachability checks before executing any physical movement.
- **LLM Brain Integration (`run_demo5_llm_brain.py`):** LLM brain integration is also not started yet.

## 3. Current Challenges & Problems
While the core simulation pipeline is functional, a critical challenge remains to be addressed to improve the system's overall scalability and application to real-world scenarios:
- **Workspace Constraints:** A significant limitation of the current setup is that the primary robotic arm operates within a fixed, static workspace. The inherent reach of the Franka Panda manipulator strictly limits the maximum size, length, and height of the wall that can be constructed. Constructing larger, more architecturally significant walls would require transitioning from a fixed base to dynamic base placement or mounting the robotic arm on a mobile base (e.g., an omnidirectional automated guided vehicle). Managing the coupled kinematics, localization, and coordination of a mobile manipulator introduces a high degree of complexity that poses a significant challenge for the scalability of the current approach.

## 4. Future Goals (Next 2 Months)
Moving into the final phases of the project, our efforts will be focused on integrating advanced intelligence and rigorously testing the system:
- **Refine LLM Orchestration:** We plan to fully transition from static, hard-coded procedures to a robust, prompt-engineered LLM brain capable of parsing and handling complex, ambiguous natural language commands. This integration will enable high-level strategic planning driven directly by human instructions, allowing users to simply describe the desired structure.
- **Improve Physics Realism:** A critical goal is to improve the fidelity of our simulation by replacing simplified mechanisms (like teleportation for the transport shuttle) with more realistic kinematic or dynamic grasping interactions. We also aim to simulate the mortar extrusion process more accurately to better model fluid dynamics, settling, and adhesion properties during construction.
- **Comprehensive Benchmarking:** We will design and run extensive automated evaluations to gather detailed quantitative metrics on placement accuracy, timeline efficiency (visualized using automated Gantt charts), and failure recovery rates. These tests will subject the system to various simulated edge cases, including random unreachable coordinates, noisy sensor data, and unexpected dynamic obstacles.
- **Final Project Deliverables:** We will focus heavily on finalizing the project documentation, preparing the final viva defense presentation, and ensuring all theoretical claims regarding orchestration capabilities and placement precision are rigorously backed by substantial and reproducible simulation data. We will also clean and package the codebase for open-source release.
